# فانتا VANTA — الموقع التعريفي + نظام الطلب الآلي

موقع تعريفي بسيط وسريع لشركة متخصصة في طباعة الأكياس والحقائب الدعائية،
مع قسم طلب آلي يحسب السعر فورًا ويُسجّل الطلب في **Google Sheets** عبر **Apps Script**.

**أولوية المشروع: كفاءة الموقع + صحة الحسابات (صفر أخطاء حسابية).**

---

## 🧮 كيف نضمن صحة الحسابات؟

| الضمان | كيف |
|---|---|
| **محرك واحد، لا نسختان** | `src/pricing-core.js` يُنسخ حرفيًا إلى الموقع (`assets/vanta-pricing.js`) وإلى Apps Script (`google-apps-script/Pricing.gs`) عبر `tools/build.mjs`. يستحيل أن يختلف الحسابان. |
| **السيرفر لا يثق بالمتصفح** | Apps Script يعيد حساب الطلب من الصفر ويخزّن النتيجة. لو اختلف رقم الموقع عن السيرفر، يُسجَّل الاثنان في عمود «مطابقة الحساب». |
| **لا أرقام عشرية إطلاقًا** | كل المبالغ أعداد صحيحة بأصغر وحدة (هللة). `25000` = `250.00`. |
| **ضرب النسب بـ BigInt** | الضريبة والاستعجال تُحسبان بحساب صحيح `amount × bps ÷ 10000` دون أي فاصلة عائمة. |
| **تقريب موحّد** | نصف للأعلى (Half-Up) في خطوة أخيرة واحدة فقط. |
| **ترتيب عمليات ثابت** | موثّق في الكود وفي هذا الملف (أدناه). |
| **رفض بدل التخمين** | أي نتيجة غير صحيحة أو مبلغ خارج النطاق الآمن ⇒ `ok:false` ولا يُسجَّل أي رقم. |
| **اختبارات آلية** | ١٧ اختبارًا للمحرك + ٨ اختبارات واجهة، بينها **٣٠٠٠ سيناريو عشوائي** تُقارَن بتطبيق مرجعي مستقل بحساب BigInt. |

### ترتيب العمليات (ثابت وموثّق)

```
1) perUnit   = سعر شريحة الكمية + مجموع دلتا الخيارات (لكل وحدة)
2) production= perUnit × الكمية
3) flats     = مجموع الرسوم الثابتة للخيارات + رسوم تجهيز المنتج
4) rush      = تقريب( (production + flats) × rushPctBps / 10000 )     ← إن طُلب
5) delivery  = (production + flats) >= حد الشحن المجاني ? 0 : رسوم التوصيل
6) taxable   = production + flats + rush + delivery
7) tax       = تقريب( taxable × taxBps / 10000 )
8) total     = taxable + tax
```

## 🎨 تخصيص الهوية البصرية

### الشعار
ضع ملف الشعار باسم **`assets/logo.png`** (أو `.svg`) — يظهر تلقائيًا في الهيدر والفوتر،
ويحل محل الشعار الافتراضي.

### الألوان
افتح `assets/styles.css`، أول ١٠ أسطر:

```css
:root {
  --ink:      #0B0C0F;   /* الأسود الأساسي */
  --accent:   #C9A227;   /* اللون المميز */
  --accent-2: #E3C567;   /* درجة أفتح للتدرجات */
}
```

غيّر هذه القيم فقط وستتحدث كل الصفحة (أزرار، شرائط، تحديدات، فوتر).

### بيانات التواصل
`assets/config.js`: الهاتف، الواتساب، الإيميل، العنوان، ساعات العمل، إحصائيات الهيرو.

## 💰 تعديل الأسعار والمنتجات

**مصدر واحد: `catalog.json`.**

```jsonc
{
  "id": "paper-bag",
  "name": "كيس ورقي دعائي",
  "minQty": 100,          // أقل كمية
  "qtyStep": 50,          // الزيادة بمضاعفات
  "tiers": [              // شرائح الكمية (تصاعديًا، والسعر تنازليًا)
    { "minQty": 100,  "unitPrice": 320 },   // 3.20
    { "minQty": 500,  "unitPrice": 275 },   // 2.75
    { "minQty": 1000, "unitPrice": 235 },
    { "minQty": 5000, "unitPrice": 195 }
  ],
  "groups": [
    {
      "id": "size", "label": "المقاس", "type": "single", "required": true, "default": "m",
      "options": [
        { "id": "m", "label": "وسط 25×12×32 سم", "delta": 25 },   // +0.25 للقطعة
        { "id": "l", "label": "كبير 32×12×40 سم", "delta": 55 }
      ]
    },
    {
      "id": "extras", "label": "إضافات", "type": "multi",         // اختيار متعدد
      "options": [
        { "id": "sample", "label": "عينة قبل الإنتاج", "flat": 12000 }  // 120.00 مرة واحدة
      ]
    }
  ]
}
```

| الحقل | المعنى |
|---|---|
| `unitPrice` | سعر الوحدة الأساسي **بالهللة** |
| `delta` | يُضاف إلى **سعر الوحدة** |
| `flat` | يُضاف إلى الطلب **مرة واحدة** |

ثم:

```bash
npm run build   # يتحقق من الكتالوج ويولّد الملفات (يرفض أي بيانات خاطئة)
npm test        # تأكيد نهائي
```

وانسخ `google-apps-script/Catalog.gs` الجديد إلى Apps Script
(التفاصيل في `GOOGLE_SHEET_SETUP.md`).

### إعدادات عامة (في `catalog.json → settings`)

| الإعداد | الافتراضي | الشرح |
|---|---|---|
| `currency` | `SAR / ر.س` | العملة وعدد الوحدات الصغرى |
| `taxBps` | `1500` | الضريبة ١٥٪ (غيّرها حسب بلدك: `500` = ٥٪) |
| `rushPctBps` | `1500` | نسبة رسوم الإنتاج العاجل |
| `deliveryFee` | `25000` | رسوم التوصيل (٢٥٠) |
| `freeDeliveryThreshold` | `300000` | توصيل مجاني فوق ٣٠٠٠ |
| `maxQty` | `1000000` | سقف الكمية للطلب الواحد |
| `leadTimeDays` | `7` | مدة التنفيذ الافتراضية |

## ⚡ كفاءة الموقع

- صفر اعتماديات في المتصفح: HTML + CSS + JS خالص (لا React ولا jQuery).
- لا استعلامات شبكة أثناء التسعير — الكتالوج مضمّن، والحساب فوري في المتصفح.
- خط عربي واحد (Tajawal) محمّل بـ `display=swap` مع بدائل نظامية.
- صور محسّنة، تحميل كسول (`loading="lazy"`) لكل ما تحت الطية.
- واجهة متجاوبة بالكامل (جوال/تابلت/سطح مكتب) + دعم `prefers-reduced-motion`.
- تخطيط ثابت (no CLS): أبعاد الصور محدّدة مسبقًا.
- بيانات منظّمة `JSON-LD` ووسوم `Open Graph` لنتائج بحث أفضل.
